# OIBSIP_java-02
The Library Management System is a console-based application developed using Java to automate and manage the daily operations of a library. This project helps in maintaining records of books, issuing and returning books, and managing library users efficiently.
The system is designed to reduce manual work, improve accuracy, and provide a structured way to manage library resources. It is well-suited for academic projects, internship submissions, and beginner-level Java practice.
🎯 Objectives of the Project
To apply Object-Oriented Programming (OOP) concepts in a real-world scenario
To understand how data can be managed systematically using Java
To automate basic library operations
To improve coding, logical thinking, and problem-solving skills
To create a simple yet effective menu-driven application
✨ Key Features
Add new books to the library
Display available books
Issue books to users
Return issued books
Search books by ID or name
User-friendly, menu-driven interface
Proper validation for book availability
Efficient handling of library records

⚙️ How the System Works
The system displays a main menu with multiple library operations
The user selects an option such as:
Add Book
View Books
Issue Book
Return Book
Exit
Each operation updates the library records accordingly
Book availability is checked before issuing
The program runs continuously until the user exits
